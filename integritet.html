Integritetsinformation

Den här sidan beskriver hur vi använder uppgifter som du lämnar i offertformuläret. Kontakta oss på flyttfrascht@gmail.com om du har frågor.

Vilka uppgifter lämnar du?

Du kan lämna namn, telefonnummer, e-postadress, tjänst, bostadens storlek, adress/område, önskat datum, prisförslag och andra uppgifter som du själv skriver i meddelandet.

Varför använder vi dem?

Vi behandlar uppgifterna för att ta emot och svara på din förfrågan, ge en offert och vid behov planera ett uppdrag.

Vilka tjänster används?

Formuläret skickas via Formspree och förfrågningar kan sparas i Supabase. Mejlkontakt kan ske via vår e-posttjänst. Dessa tjänster kan behandla information för vår räkning.

Frågor och begäran om radering

Kontakta oss via flyttfrascht@gmail.com om du vill fråga om dina uppgifter eller begära rättelse eller radering.

Inför publicering: Komplettera denna information med företagets fullständiga juridiska namn, organisationsnummer, kontaktadress, rättslig grund, lagringstider och relevanta uppgifter om eventuella överföringar. Denna sida är en grundtext, inte en fullständig juridisk granskning.

Besöksstatistik

Vi använder Cloudflare Web Analytics för att förstå hur vår webbplats används och förbättra våra tjänster.

Vi kan se antal besök, vilka sidor som besöks och varifrån trafiken kommer. Cloudflare Web Analytics använder inte cookies för denna besöksstatistik, men viss teknisk information kan behandlas.
